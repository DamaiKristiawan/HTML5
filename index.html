Informasi Sistem

Sistem Informasi Data Mahasiswa ini digunakan untuk mengelola data mahasiswa, termasuk menambahkan, mengedit, dan menghapus data mahasiswa.

Fitur Utama

  • Menampilkan daftar mahasiswa
  • Menambahkan data mahasiswa baru
  • Mengedit data mahasiswa yang sudah ada
  • Menghapus data mahasiswa
